# Knight Adventure

## Описание игры

Knight Adventure — это 2D-игра в жанре Action/RPG, разработанная на игровом движке Unity.

Игрок управляет рыцарем, который исследует уровни, сражается со слизнями (Slime), собирает предметы восстановления здоровья и должен уничтожить всех врагов для прохождения уровня.

После уничтожения всех врагов происходит переход на следующий уровень. В случае гибели персонажа отображается экран поражения.

## Управление

* WASD или стрелки — перемещение персонажа.
* Левая кнопка мыши — атака мечом.
* Кнопки интерфейса используются для навигации по меню и перезапуска игры.

## Запуск проекта

1. Открыть проект в Unity.
2. Открыть сцену MainMenu.
3. Нажать кнопку Play в редакторе Unity.

Для запуска готовой версии:

1. Открыть папку Build.
2. Запустить файл KnightAdventure.exe.

## Использованные технологии

* Unity
* C#
* Unity Input System
* NavMesh Agent (навигация противников)
* Animator Controller
* Tilemap
* Coroutine
* UI Toolkit / Canvas UI

## Игровые механики

* Перемещение персонажа.
* Ближняя атака мечом.
* Система здоровья игрока.
* Система здоровья врагов.
* Искусственный интеллект противников.
* Преследование игрока.
* Подбор аптечек.
* Экран победы и поражения.
* Переход между уровнями.
